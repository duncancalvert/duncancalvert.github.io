When you visit this site we automatically collect technical signals from your browser and device, such as browser and operating system details, screen and hardware characteristics, language and time zone, your IP address and approximate location. We also record how you interact with the page: mouse, touch, scroll and typing _timing_, never what you type. A random identifier is stored in a cookie and in local storage so we can recognise the same browser on return visits.

We use this information only for security and fraud prevention, for example to detect bots, account takeover and repeated abuse. We do not sell it or use it for advertising.
